# Changelog

## 0.1 — template

First public template of the reading game kit.

- Reading adventures: decodable stories read in small caps, then lowercase, with two parallel tracks.
- Four mini games (Crafting Table, Word Blocks, Letter Mine, Bridge Match) with phonics-ladder levels and level-up surprises.
- A village shop with 13 professions plus a Wandering Trader, villager promotions, Treasure Pile and Send.
- Optional Minecraft delivery (off by default): Magic Chest shrine, Magic Necklace data pack, installer.
- Optional away-from-home website copy (off by default) with a Send export file and an import on the home computer.
- Optional real-texture art mode, built locally from the parent's own Minecraft jar and never committed.
- Personalisation through `config/family.json` (child name, village name, grown-up label, away-from-home label).
