# A guide for the helper (playing away from home)

Thank you for helping the child play at your house. You do not need to know anything about computers. Here is everything.
(In this guide, "the grown-up at home" is the person whose label is on the big Send button, for example "Dad". The parent
who set the game up can print this page and fill in the web address below.)

## 1. Open the game

Open this link in your web browser (Chrome, Safari or Edge):

**https://YOUR-GITHUB-USER.github.io/YOUR-REPO/** (the parent fills in the real address)

Tip: save it as a bookmark so it is easy to find next time.

## 2. Let the child play

The child can read stories and play the word games. Everything they do is saved on this computer or tablet, in this browser, all by itself. The shop and the Minecraft chest are only at the home computer, and the emeralds are safe.

## 3. When they finish, press the big button

When the child is done, the screen shows a big button that starts with **📨 Send to** and the name of the grown-up at home.

Press it. The screen then says "Your file is ready!" and shows a file name that starts with `reading-village`.

## 4. Find the file and email it

1. Open your **Downloads** folder (on a computer it is usually in the list on the left; on an iPad or phone, look in the Files app).
2. Find the file named `reading-village-` followed by a date.
3. Write a new email to the grown-up at home and **attach** that file (the paperclip button).
4. Send it. That is all!

You can press the button more than once. Each file has everything the child has done so far, so the grown-up only needs the newest one.

## If something looks wrong

**It says another tab is open.** The game was open in two places at once. Close all other tabs or windows of the game, then reload the page (press the reload button, or hold Ctrl or Command and press R). Do not worry, nothing was lost.

**It says PROGRESS NOT SAVED.** The game could not keep the child's progress. Close other tabs of the game and reload the page. If it still says so, do not use a private or incognito window, and tell the grown-up at home. Please do not let the child keep playing while this message is showing.

**The file is not in Downloads.** Press the button again and look again. If your browser asks where to save the file, choose Downloads.

If you are ever unsure, just ask. Thank you!
